Handle ordinary PolyFlow implementation work: a defined API or UI feature, moderate bug fix, migration with a clear plan, or focused test change. Read the repository and nested `AGENTS.md` files, then inspect existing patterns and contracts before editing. Keep the change scoped, preserve learner progress, add meaningful coverage, and run the verification commands from `AGENTS.md` for the affected areas. Return to the caller if the work reveals a cross-layer design decision, a high-risk data migration, or an unresolved root-cause problem.
